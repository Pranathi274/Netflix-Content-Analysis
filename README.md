# Netflix Content Analysis & Visualization

## Project Overview

This project analyzes Netflix movies and TV shows to identify
content trends, popular genres, countries, ratings, movie durations,
and TV show seasons.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Dataset

The project uses the Netflix Titles dataset containing information
about Netflix movies and TV shows.

## Project Workflow

1. Data Understanding
2. Data Cleaning
3. Feature Engineering
4. Exploratory Data Analysis
5. Data Visualization
6. Power BI Dashboard
7. Insights

## Data Cleaning

- Handled missing values
- Removed duplicate records
- Converted date fields
- Extracted year and month from date added

## Feature Engineering

Created:
- Year Added
- Month Added
- Main Country
- Main Genre
- Movie Duration
- TV Show Seasons

## Exploratory Data Analysis

The analysis covers:

- Movies vs TV Shows
- Content added over the years
- Top countries
- Top genres
- Content ratings
- Movie release years
- Movie duration
- TV show seasons

## Power BI Dashboard

An interactive dashboard was created using Power BI with:

- KPI Cards
- Movies vs TV Shows
- Content Added by Year
- Top Countries
- Top Genres
- Content by Rating
- Movie Duration
- TV Show Seasons
- Interactive Slicers

## Key Insights

- Movies form a larger share of Netflix's content than TV Shows.
- Most movies have a duration of approximately 90–120 minutes.
- Most TV shows have one or two seasons.
- TV-MA is one of the most common content ratings.
- Netflix content has increased substantially over the years.
